# Cozy Desk の記事の書き方

白デスク・淡色デスク(#淡色界隈・#デスクレシピ)が好きな人に向けて、白と淡い色のガジェットを紹介するサイト。
収益は紹介料(楽天・Amazon・Yahoo!ショッピング)。読んだ人が「同じ物を買いたい」と思え、迷わず買える記事にする。

## 記事は2種類

| kind | 中身 |
|---|---|
| `new` | 海外の新作1つを紹介する。記事末に「日本で買える？使える？」(`japan:`)を必ず書く。近い物を日本で探すボタン(`alt_q:`)をつける |
| `buy` | 日本で今買える白・淡色の物を3〜5個まとめる(`products:`)。1つずつ買うボタンがつく |

## 週の割り振り(2026-10-31 本人と決定)

- 週3本: `new` 2本(1商品1記事でしっかり書く)＋ `buy` 1本
- `buy` は1本7〜8点のまとめ。2周目からは新しい記事より、今の記事の物と値段の入れ替えを優先。新しく作るなら種類をまたぐ切り口(「ピンクだけでそろえる」「1万円以下で白くする」など)
- 選び方・付け方の説明が多い物(間接照明など)は、日本で買える物でも1商品1記事にしてよい
- X では、まとめの物も1つずつ見せ、リンクはその物の場所(`/p/<記事>/#item-番号`)へ

## いちばん大事なこと: このサイトの目的は紹介料

載せる物・記事の形・言葉は、「読んだ人がボタンを押して買うか」で決める(2026-10-31 本人)。

- **`buy` に載せる物は、楽天・Amazon・Yahoo!ショッピングの「1つ以上」で、メーカーか正規の店(公式ストア・大手量販店・PC専門店)が売っている物。** 3つ全部そろっている必要はない。1つでも買えれば載せる(2026-10-31 本人)。どこでも売っていない物(IKEA など)は、代わりの無いときだけ載せ、ボタンの代わりに公式ストアのリンクを書く
- 売っているストアが分かったら、物ごとに `stores: [rakuten, yahoo]` のように書く。書いたストアのボタンだけが出る(無い店のボタンを押させて、押し損にしないため)。書かなければ3つ出る
- `q` は、3つのストアの検索でその物が一番上に出る言葉にする(型番＋色)。書いたら実際に検索して確かめる
- `new` の `alt_q` は、3つのストアで実際に売っている近い物に当たる言葉にする

## 絶対に破らない決まり(Gadget Terminal と同じ)

- **公式ページで確かめた事実だけを書く。** 値段・大きさ・重さ・色の名前・つなぎ方は、メーカー公式ページか公式ストアで確かめる。確かめられなければ書かない
- **値段には「掲載時点」とつける。** 日本で買える物は円で、メーカー公式ストアか公式の希望小売価格。量販店の一時的な値引きは書かない
- **色の名前はメーカーの呼び方を使う**(例: オフホワイト、ローズ、ミルクティー)。`hex` は公式写真の見た目に近い淡い色を選ぶ
- **使ってみた感想を書かない。** 「使ってみると」「手に取ると」「実際に座ると」は禁止。編集部は使っていない
- **「技適」という言葉と、専門用語を出さない**(2026-10-31 本人判断。GT とはここが違う。読む人は「技適」と言われてもわからない)
  - 裏では GT と同じく、無線の物が日本向けの正規品か(技適があるか)を確かめる。書くときは「日本の正規品」「日本の公式ストアで販売」のような、ふつうの言葉にする
  - 日本向けか確かめられない無線の物は、なるべく選ばない。海外の新作(`new`)なら `japan:` に「無線で使うなら、日本向けの発売を待つのが安心です」のように、やさしく書く
  - 規格の言葉も言いかえる: 「2.4GHz Wi-Fi」→「スマホのアプリで操作」、「TRS・RCA・XLR」→「ケーブルでもつなげる」、「USB Type-A」→「USB でつなぐ」。大きさは cm で丸める
- **画像はメーカー公式ページ・公式ストアの画像URLを直接書く**(ダウンロードしない)。出典を必ず書く。ニュースサイト・個人ブログ・Amazon の画像は使わない。URL が実際に開けることを確かめる(Shopify の `cdn/shop/files/...` など)
- 煽らない。感嘆符と絵文字を使わない
- 円換算は書かない(海外の値段はドルのまま)

## 文の調子

- 短く、やわらかく。「〜です・〜ます」。むずかしい言葉は使わない(「エルゴノミクス」→「体に合わせて調整できる」)
- 何がかわいいか・白デスクにどう合うかを、色・形・素材の事実から書く
- `summary` は1〜2文。検索結果にそのまま出る

## ファイル

`content/posts/YYYY-MM-DD-<英小文字の短い名前>.md`。front matter の値に `:` が入るときはダブルクォートで囲む。

```yaml
---
title: "白いPCケース、日本で今買える5つ。ガラス越しに淡く光る"
date: 2026-10-31
category: pc          # desk chair pc monitor mouse keyboard speaker gear interior
kind: buy             # new か buy
summary: "…"
thumbnail: "https://…"           # 一番目立つ公式画像。無ければ書かない
thumbnail_alt: "…"
thumbnail_credit: "NZXT 公式サイト"
thumb_fit: true                  # 切り抜き写真(白背景の製品画像)なら true、部屋の写真なら書かない
colors:                          # その記事の物の色(サイトの一覧に丸で出る)
  - {name: ホワイト, hex: "#F7F6F2"}
products:                        # buy のとき
  - name: "NZXT H6 Flow ホワイト"
    image: "https://…"           # 公式の製品画像
    image_credit: "NZXT 公式サイト"
    price: "1万9,800円(掲載時点・公式ストア)"
    colors: [{name: ホワイト, hex: "#F7F6F2"}]
    note: "1〜2文。何がかわいいか、白デスクにどう合うか"
    jp: "日本の正規販売品 ・ ATX 対応"     # 日本での買いやすさ・つなぎ方・大きさなどを、ふつうの言葉で
    q: "NZXT H6 Flow ホワイト"   # 楽天・Amazon・Yahoo で検索する言葉。型番＋色が確実
    # category: gear             # 記事の種類と違う物のときだけ(デスクレシピなど)。種類のページの「色で選ぶ」に並ぶ
    # 色の系統(白・ピンクなど「色で選ぶ」のボタン)は hex から自動。外れるときだけ colors に tone: ピンク のように書く
    # facets: {width: 160cm以上, shape: 昇降}  # デスクだけ必須。種類ページは色でなく横幅・形で選ぶ(値は config/site.yaml の facets)。ガジェット好きは昇降式が多いので、机を足すときは昇降を優先
    # 同じ物を別の記事で使い回すときは name を一字一句そろえる(種類のページで重ならないように)
sources:
  - {name: NZXT 公式サイト, url: "https://…"}   # 確かめたページを全部
---

本文(Markdown)。buy のときは、選び方(何を見て選ぶか)を2〜4項目、短く。
各製品の説明は products に書くので、本文で同じことを繰り返さない。
```
