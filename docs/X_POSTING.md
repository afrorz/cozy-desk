# X(@Cozy_Desk)の投稿の決まり

投稿するのは管理人キャラクターのシロネ(docs/CHARACTER.md)。2026-11-04 本人が口調と型を決めた。

## 口調

- 一人称は「わたし」
- 少し眠そうで、短い文。語尾は「〜かも」「〜だよ」「…」をときどき。はしゃがない
- 言わないこと: 使った感想(最高・手放せない など)、経歴や体験(買った・届いた・使っている)、値段の煽り
- 事実は記事と同じく、公式で確かめたものだけ

## 型(11/4 夕方に本人と組み直した)

X で白・淡色デスク界隈を調べた結果(`notes/desk-gadgets/x-competitors-2026-11-04.md`): 伸びているのはほぼ自分の机の実写で、実物を持たない Cozy Desk は実写では勝てない。大きさ比べの投稿は1件も無かった。

1. **新作**(柱、本人の案): メーカーから出たばかりの新作。まだ誰も実物を持っていないので、公式写真だけでも条件が同じになる。発表・予約開始の当日に出す。画像は公式写真＋隅にシロネの顔のスタンプ、本文はシロネの一言。リンク(記事)は返信、#PR
   - **色は基本白。かわいければ白にこだわらない**(本人)
   - **X では「日本で買えるか」を言わない**(本人)。「買えない」と書くと誰もサイトに来ない。日本で買えるかは記事の中で書く
2. **デスクレシピ**(ときどき。本人が見本を見て「たまに投稿してもいい」): まとめ記事の物を縦長1枚(1200×1500)にカードで並べ、シロネが「買える場所は、返信のリンクから」。保存されやすい形。#PR、リンクは返信
3. **1本の記事をいろんな切り口で**: まとめの物を1つずつ、写真＋隅のシロネで(記事を選別しない、本人の方針)。#PR、リンクは返信(`#item-番号`)
4. **選ぶ問い**: 「AとB、どっち？」。リンクなし・広告ではない
5. **机の上のシロネ**: たまに。シロネの絵と一言だけ。物の感想は言わない。リンクなし

- 大きさ比べ(わたしより◯cm高い)は柱にしない。小ささが売りの物のときだけ、本文の一言か画像のおまけで使う(「大きい物と比べても意味がない」と本人)

## 広告の示し方

紹介料のつくリンクを貼る投稿・物を勧める投稿には、投稿ごとに「#PR」を入れる(2023年10月からのステマ規制。プロフィールに書くだけでは足りない)。

## 投稿の流れ

最初は投稿の前に本人が確かめる。問題が出なくなってきたら自動投稿にする(本人の判断)。

いま(2026-11-04〜)の形は「下書きを x-poster に並べ、本人が確かめてコピペで投稿」(本人が案1を選んだ。API の投稿費はかからない):

1. Claude が下書きを作る: 画像は `scripts/x_render.py` で作って `assets/x/<id>.jpg` に置き、文は `x/drafts/<日付>.json`(公開リポジトリに出さないため git に入れない)
2. Cozy Desk を push して画像を公開する
3. x-poster のフォルダで `node scripts/push-cozy.mjs <drafts.json のパス>` を実行して、x-poster の「Cozy」タブへ送る(画像が開けないと止まる)
4. 本人が Cozy タブで確かめ、本文コピー → 画像を添付して投稿 → 返信の文があれば返信に貼る →「投稿した」
5. 直したい所を言われたら、同じ id で直して送り直す(投稿前なら差し替わる)

下書きの `memo` には、数字の出どころ(公式の大きさなど)を書いておき、本人が確かめやすくする。

## 画像の作り方

- 背景は継ぎ目のない撮影用の背景(上の淡いラベンダーから下の白へ)。壁と机の境目の線を入れない(本人が「不自然」と指摘)。部品は `scripts/x_render.py`
- **写真＋隅のシロネ**(新作・切り口): 1200×675。物の公式写真を rembg(isnet-general-use)で切り抜いて大きく置き、右下にシロネの顔の丸いスタンプ(`docs/character/shirone/face_*.png`、表情は物に合わせて選ぶ)
- **デスクレシピ**: 1200×1500。上に看板の言葉(小さい一言＋題)、2列のカードに写真・番号・名前・特徴2行、下にシロネと「買える場所は、返信のリンクから」
- **大きさ比べ**(おまけ): 物は本体だけで高さをそろえる(コードは入れない)。シロネは設定画の斜めの姿(目の透けは元の色で埋める)を背丈10cmで
- 左下に出典(「画像: ◯◯ 公式サイト・Cozy Desk(シロネ)」)
- 公式サイトがプログラムからの取得を断る写真(エレコムなど)は、ブラウザで開いて画面から取る。リファラーの偽装はしない
