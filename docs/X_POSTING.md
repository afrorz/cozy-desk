## 広告の示し方

**2026-11-22 から、本文の「#PR」はやめて、X の「有料パートナーシップ」の設定で示す(本人判断)。** 物を勧める投稿(新作・デスクレシピ・切り口・まとめ1枚)は、本人が投稿するときに設定をオンにする。下書きの本文には #PR を入れない。選ぶ問い・机の上のシロネ(リンクなし)は付けなくてよい。

- 理由: ステマ規制(2023年10月〜)の対象は内容の決定に関与した広告主で、依頼を受けずに自分で紹介する今の投稿は当たりにくい(消費者庁 Q&A の Q1)。それでも紹介料のある記事へ送るので、投稿そのものに広告と分かる印は残す。有料パートナーシップのラベルは投稿の上に出るので、本文のタグより目立ち、タグの枠も1つ空く
- 「飛んだ先の記事に PR と書いてあるから投稿側は要らない」は通らない。消費者庁 Q&A の Q14 は、返信(ツリー)に書くだけでも「明瞭とはいえない場合が多い」としている。印は投稿そのものに付ける
- **メーカーから物の提供・投稿の依頼を受けた投稿は、有料パートナーシップに加えて本文にも「#PR」か「◯◯社から提供を受けて投稿」を入れる**(広告主の表示に当たるため)

## 投稿の流れ

最初は投稿の前に本人が確かめる。問題が出なくなってきたら自動投稿にする(本人の判断)。

いま(2026-11-04〜)の形は「下書きを x-poster に並べ、本人が確かめてコピペで投稿」(本人が案1を選んだ。API の投稿費はかからない):

1. Claude が下書きを作る: 画像は `scripts/x_render.py` で作って `assets/x/<id>.jpg` に置き、文は `x/drafts/<日付>.json`(公開リポジトリに出さないため git に入れない)
2. Cozy Desk を push して画像を公開する
3. x-poster のフォルダで `node scripts/push-cozy.mjs <drafts.json のパス>` を実行して、x-poster の「Cozy」タブへ送る(画像が開けないと止まる)
4. 本人が Cozy タブで確かめ、本文コピー → 画像を添付 → 「有料パートナーシップ」をオン → 投稿 → 返信の文があれば返信に貼る →「投稿した」
5. 直したい所を言われたら、同じ id で直して送り直す(投稿前なら差し替わる)

下書きの `memo` には、数字の出どころ(公式の大きさなど)を書いておき、本人が確かめやすくする。
