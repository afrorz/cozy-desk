## シロネの推しポイント

朝、机に向かう前に、イヤーパッドの色を決める。今日はブルー、明日はオレンジ。MDR-3R には、その2色のイヤーパッドが最初から両方入っています。ソニーは「ブルーかオレンジ。今日はどちらにする？」と紹介しています。

本体は明るいシルバー。白い机の上でも浮かず、パッドの色だけがぽつんと差し色になります。公式は、耳に着けるだけでなく首にかけてファッションとしても楽しめる、と説明しています。

つなぐのは USB-C のケーブル1本。充電もペアリングもいらないので、「使おうと思ったら電池が切れていた」が起きません。スマホにも PC にも、さしたらすぐ聴けます。

## ここがかわいい

- 形のもとは、1979年に初代ウォークマンと一緒に生まれたヘッドホン「MDR-3」。ソニーのロゴ、「Dynamic Stereo Headphones」の刻印、ヘッドバンドの形、音の穴まで、元の形を細かく受け継いでいます
- 細いヘッドバンドに、小さな丸い耳あて。重さは約38g(ケーブルを除く)で、公式によると今のソニーの頭にかけるヘッドホンの中でも特に軽い作りです
- イヤーパッドはブルーとオレンジの2色入り。どちらも元の MDR-3 をもとにした色です
- 本体にはアルミとステンレスを使っています
- 箱と説明書も、元の MDR-3 に寄せたデザイン

## 大きさと使い方

| | |
|---|---|
| 色 | シルバー(MDR-3R SC)。ソニーストア限定で「ストレンジャー・シングス」エディションもあります(イヤーパッドはレッドとブラック) |
| 重さ | 約38 g(ケーブルを除く。大きさは公式に掲載がありません) |
| つなぎ方 | USB-C でつなぐ有線のヘッドホン。スマホ・タブレット・PC につなげます。充電とペアリングはいりません |
| 手元の操作 | ケーブルの途中にリモコンとマイク。再生・止める・曲送り・音量を変えられ、通話やオンライン会議にも使えます |
| ケーブル | 約1.2 m。表面に細かい溝があり、からまりにくい作り |
| 耳あて | 耳の上にのせる形で、外の音も少し聞こえる開いた作り(オープンエア) |
| 同梱 | イヤーパッド ブルー・オレンジ |
| 値段 | 7,700円(掲載時点・ソニーストア。メーカー希望小売価格はオープン) |
| 発売 | 2026年11月20日予定。ソニーストアと各店で予約受付中 |

公式によると、つなぐ機器によっては設定が必要だったり、動かない機能があったりします。ウォークマンにつないで使うことは、ソニーはすすめていません。
