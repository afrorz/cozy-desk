## シロネの推しポイント

朝、机に向かうと、白い天板の端に練り絹のような白のヘッドホンがひとつ。いつもの机に、和の色が加わります。白練(しろねり)は、クリームに近いやわらかな白。白い机にも、木の机にもすっとなじみます。

もうひとつの梅染(うめぞめ)は、梅の木から生まれる赤みの茶色。ピンクともブラウンとも言い切れないくすんだ色で、ベージュやピンクの小物とそろえたくなります。

電池は、ノイズを消す機能をつけたままで約72時間。公式によると、1日2.5時間なら充電は約1か月に1回で足ります。「気づいたら電池が切れていた」が起きにくいので、机の上の飾りのように置いておいて、手に取ったらそのまま使えます。

## ここがかわいい

- 色の名前は、日本の伝統色から。白練(しろねり)・梅染(うめぞめ)・漆黒(しっこく)の3色です
- 丸い耳あてに、細い1本のアーム。公式は「やわらかな丸みを帯びたシンプルなフォルム」と説明しています
- ヘッドバンドと耳あてのクッションは、公式が「やわもち」と呼ぶ、もちもちした触り心地の素材
- 耳あてを内側に回せるので、首にかけてもかさばりにくい形です
- 2通りに折りたためます。平らにする「フラット」と、小さくまとめる「コンパクト」
- 箱は紙のパッケージ

## 大きさと使い方

| | |
|---|---|
| 色 | 白練(RB-HJ800-W)・梅染(RB-HJ800-T)・漆黒(RB-HJ800-K) |
| 重さ | 約260 g(大きさは公式に掲載がありません) |
| つなぎ方 | Bluetooth。付属のコード(約1.2 m)で有線でも使えます。2台まで同時につなげます |
| 電池 | 約72時間(ノイズを消す機能をつけたまま)、約100時間(その機能を切ったとき)。空から満充電まで約4時間 |
| 急速充電 | 15分の充電で約8時間 |
| 同梱 | 本体・着脱コード。充電用の USB-C ケーブルは付属しないので、手持ちの物を使います |
| 値段 | 14,986円(掲載時点・パナソニック公式の楽天市場店。メーカー希望小売価格はオープン) |
| 発売 | 2026年11月中旬(店の予約ページでは11月19日の表示) |

ノイズを消す機能(ノイズキャンセリング)と、外の音を聞きながら使うモードを切り替えられます。低音を強めるボタンも本体についています。

梅染がほしいときは、店の検索を「RB-HJ800-T」に変えてください。
