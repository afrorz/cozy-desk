## シロネの推しポイント

白いキーボードのキーを、ぜんぶ水色に替えてみる。すりガラスのように透ける水色のキーが並ぶと、机の上に小さな海ができたみたいです。NuPhy がデザイナーの Lele Design と作ったキーキャップ「Ocean Blue」です。

いつもの文字のキーにまじって、くじら・いかり・ヤシの木・ヨット・コンパスの絵のキーが入っています。どこに置くかを考えながら付け替える時間も、ちょっと楽しくなりそうです。

![白い NuPhy のキーボードに Ocean Blue を付けたところ。濃い青のキーに、白い線でくじらの尾](https://pbs.twimg.com/media/HXkOeRZaUAA8xCn?format=jpg&name=large)

## ここがかわいい

- すりガラスのように、うっすら透ける水色
- esc と enter、くじらの絵のキーだけが濃い青
- 海の絵のキー: くじら・いかり・ヤシの木・ヨット・コンパス・浮き輪・灯台・かもめ・ボトルの手紙など
- 白いキーボードに付けると、水色と白の2色になります
- 作ったのはデザイナーの Lele Design。セットには Lele Design のロゴのキーも入っています

![白いキーボードに付けた Ocean Blue をななめ上から。まわりに透ける青いキーと、青いクリップ](https://pbs.twimg.com/media/HXkOdkpbAAEfv3K?format=jpg&name=large)

## 大きさと使い方

| | |
|---|---|
| キーの数 | 134個 |
| キーの形 | Keytok(NuPhy の薄いキーボード用の低い形) |
| 素材 | PC(ポリカーボネート)、文字と絵は UV 印刷 |
| 長いキー | シフトなど 2.75u・2.25u・1.75u、スペース 6.25u |
| 付けられるキーボード | NuPhy の Air75 V3(Raycast・Moonbow 版をふくむ)・Air65 V3・Air100 V3・Air60 HE・Air75 HE・Kick75 Low-profile・Node シリーズ Low-profile |
| デザイン | Lele Design |

- NuPhy の公式ストアで売られているのは、キーキャップだけのセットです。キーボードは別に用意します
- 公式の写真のキーは、英語配列の並びです。日本語配列のキーボードに付けるときは、合わないキーが出ることがあります
