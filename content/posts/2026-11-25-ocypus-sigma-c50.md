## シロネの推しポイント

白いPCケースの台座が、ピンクから水色へふわっと光る。Ocypus の新しいケース「Sigma C50 ARGB」の白は、台座の上の縁にU字の光の帯が入っていて、ケースが少し浮いているように見えます。光り方は、マザーボードの光とそろえることもできます。

前の面は、角までなめらかに回り込むU字のガラス。継ぎ目の少ないガラス越しに、中の白い部品やファンの光がよく見えます。部品を白でそろえていく楽しみも広がりそうです。

USB の差し口と電源ボタンは、台座の前にまとまっています。机の上に置いたままでも、USBメモリやイヤホンをさっと差せて、ケースの後ろへ手をのばさなくてすみます。

![白いPCケースの台座の前を近くから。差し口とボタンが横一列に並び、その上の縁がピンクと水色に光る](https://www.ocypus.com/uploads/image/20261109/56cf77b9557f22ee9aef52c39130e3dd.png)

![白いPCケースを黒い机に置いたところ。ガラス越しに白いファンと小さな画面が見え、台座の縁がやわらかく光る](https://www.ocypus.com/uploads/image/20261109/e45e3f18ffb0f78a58c294b527ec619d.jpg)

## ここがかわいい

- 色は白(WH)。本体も、中の板も白
- 前の面は、角まで回り込むU字のガラス。さっと取り外せる作り
- 左右の網の面も外せるので、部品を入れるときや入れ替えるときに中へ手が届きやすい
- 左右・上・下・後ろは、細かい穴の網。ほこりよけの網も入っています
- 台座の上の縁に、U字に光る帯
- 最初から、光る 120mm のファン(Ocypus の Gamma F12 Elite ARGB)が3つ付いています。ファンの枠も白です
- 電源を付ける台は取り外せて、付ける位置も変えられます
- 同じ形の黒(BK)もあります

## 大きさと使い方

| | |
|---|---|
| 大きさ | 幅31.5×奥行25.7×高さ50.8cm |
| 重さ | 7.9kg |
| 入るマザーボード | Micro-ATX・Mini-ITX |
| グラフィックボード | 長さ40cmまで(拡張スロットは4つ) |
| ストレージ | 3.5インチ 1+1台・2.5インチ 1+2台 |
| CPUクーラー | 高さ17cmまで |
| 電源 | ふつうの ATX 電源(長さ20cmまで) |
| 水冷 | 横に 240mm・360mm のラジエーター |
| 付いているファン | 120mm の光るファン3つ。付けられるのは上2つ・横3つ・下1つの全部で6つまで |
| 前の差し口 | USB(Type-C)1つ・USB 2つ・イヤホン、電源ボタン・リセットボタン |
| 付属品 | 小さな画面を立てる台・電源ケーブル・光る帯 |
| 素材 | 鋼板(厚さ0.8mm)・樹脂・強化ガラス |

- 縦に長い形なので、机の上でも置く場所の幅は31.5cmほどです
- ケースだけの商品です。パソコンの部品は別に用意します
- 白の型番は Sigma-C50-WHG300XX-GL です
- 公式の写真の中の小さな画面は、ケースには付いていません(付いているのは画面を立てる台です)
