白いデスクには、キーボードの色もそろえたくなります。ここでは、ロジクールと Keychron の日本の公式ストアで扱っている、淡い色のキーボードを8つ紹介します。どれも日本語配列です。

キーボードは、見た目だけで選ぶと「机に収まらない」「使いたい機器とつながらない」ということが起きます。8つの下に、[買う前に見る所と、8つの比べ表](#erabikata)をつけました。

## 買う前に見る所 {#erabikata}

数字はどれもメーカーの公式ページの値です。

## 選び方1: 大きさは「テンキー」があるかで決まる

テンキーは、右側にまとまった数字のキーです。数字をたくさん打つなら便利ですが、そのぶん横に長くなり、マウスを置く場所が右へずれます。

- **テンキーなし(横幅28〜33cm)。** Pebble Keys 2(27.9cm)・Keychron B3 Pro(29.7cm)・POP Icon Keys(32.5cm)の3つです。机をすっきり見せたい人や、持ち運びたい人に向いています
- **テンキーつき(横幅37〜46cm)。** K580(37.4cm)・Alto Keys K98M(40.1cm)・MX Keys S(43.0cm)・K950(43.4cm)・K650(45.7cm)の5つです
- K650 は手首をのせる所が本体についていて、奥行が19.4cm あります。ほかの7つは12.4〜14.7cm です
- 色や形はほかの物が気に入っても、机の横幅が足りないことがあります。机の横幅は[図で確かめる道具](/tools/desk-size/)で試せます

## 選び方2: 厚さと重さ

- **薄い物。** 一番薄いのは B3 Pro で、手前0.9cm・奥1.5cm です。次が Pebble Keys 2 の1.6cm です。K580・MX Keys S・POP Icon Keys・K950・K650 は2.1〜2.4cm です
- **厚い物。** Alto Keys K98M は厚さ4.0cm で、8つの中では1つだけ厚めです。メカニカルという作りのキーボードです
- **重さ。** 軽いのは B3 Pro(約410g)と Pebble Keys 2(約415g)です。一番重いのは Alto Keys K98M の約1.1kg です。カバンに入れて持ち歩くなら、軽い2つが向いています

## 選び方3: 日本語配列と、Mac・iPad で使えるか

- 8つとも、日本の公式ストアで日本語配列を売っています。Keychron B3 Pro は、キーにひらがなが書かれていない日本語配列です
- 8つとも、Mac で使えると書かれています。POP Icon Keys と K950 は、キーに Windows 用と Mac 用の両方の表示があります
- iPad で使えると書かれているのは、Pebble Keys 2・POP Icon Keys・K580・K950・MX Keys S・Alto Keys K98M の6つです。K650 と B3 Pro には、iPad の記載がありません

## 選び方4: つなぎ方と、何台まで切り替えられるか

Bluetooth(ブルートゥース)は、パソコンやタブレットに元から入っている無線のしくみです。受信機は、パソコンの USB の差し込み口に挿す小さな部品です。

- **Bluetooth だけ。** Pebble Keys 2 と POP Icon Keys の2つです。Bluetooth が入っていないパソコンでは使えないことがあります。Pebble Keys 2 は、ロジクールの受信機(Logi Bolt・別売)を買い足せばつなげます
- **受信機つき。** K580・K650・K950・MX Keys S・Alto Keys K98M・B3 Pro の6つは、受信機と Bluetooth のどちらでもつなげます。B3 Pro は USB ケーブルでもつなげます
- **切り替え。** パソコン・タブレット・スマホを行き来するなら、台数を見ます。3台まで切り替えられるのは、Pebble Keys 2・POP Icon Keys・K950・MX Keys S・Alto Keys K98M・B3 Pro の6つです。K580 は2台までです。K650 は切り替えの記載がありません

## 選び方5: 電池と、キーが光るか

- **乾電池。** Pebble Keys 2・POP Icon Keys・K580・K950 は単四電池2本、K650 は単三電池2本で動きます。持ちは24〜36か月と長く、充電の手間がありません
- **充電式。** MX Keys S・Alto Keys K98M・B3 Pro の3つです。MX Keys S は、光る設定のままで最長10日、光を消すと最長5か月持ちます。Alto Keys K98M は、光を消して最長12か月です。B3 Pro は最大300時間です
- **光るキー。** 暗い部屋で打つなら、キーが光る物が見やすくなります。光るのは MX Keys S(手を近づけると光る)と Alto Keys K98M(白く光る)の2つです。K650・K950・Pebble Keys 2・B3 Pro は光らないとメーカーが書いています。K580 と POP Icon Keys は記載がありません
